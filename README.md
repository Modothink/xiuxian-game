# 打工人的修仙之路

> 在微信聊天窗口里修仙的摸鱼放置游戏。单 HTML 文件，浏览器即开即玩，Esc 一键切伪装。

## 玩法

- 自动修炼积攒灵力 → 突破境界
- 渡劫卡点小游戏（绿色区域按空格=成功率+30%）
- 梅花易数每日占卜
- 炼丹 / 法宝系统
- 离线收益（关浏览器继续修炼）

## 打开方式

[在线玩](https://modothink.github.io/xiuxian-game/) | 或直接打开 `index.html`

## 伪装

- `Esc`：微信 ↔ 游戏 切换
- `Ctrl+Shift+H`：老板键

## 技术

单 HTML 文件，Vanilla JS + localStorage，无框架无依赖。部署 = 上传文件。
